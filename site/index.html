Turn any URL into a link preview.

A Go library, CLI and HTTP API. One call returns the title, description, image, favicon, Open Graph, Twitter Cards, JSON-LD and oEmbed, with absolute URLs.

Get started pkg.go.dev Reference

What your app can render from one metagrab.Fetch call.

01Install and fetch

Go 1.26 or newer. No CGO, no headless browser.

go get github.com/josephgoksu/metagrab@latest
// Turn a URL into a preview.
link, err := metagrab.Fetch(ctx, url, metagrab.PreviewFields)
if err != nil {
    return err // *metagrab.FetchError with a Code
}
fmt.Println(link.Title, link.Image, link.Favicon)

You get a *metagrab.Link. As JSON:

link.json
{
  "url": "https://blog.example.com/posts/fast-previews",
  "title": "Making link previews fast | Example Blog",
  "description": "How to unfurl a link in under a millisecond.",
  "open_graph": {
    "og:image": "/img/cover.png",
    "og:site_name": "Example Blog",
    "og:title": "Making link previews fast"
  },
  "twitter": { "twitter:card": "summary_large_image" },

  "canonical_url": "https://blog.example.com/posts/fast-previews",

Note that og:image was relative and image is absolute. Already have the HTML? Use metagrab.Parse(r, url, mask).

02Which fields should I ask for?

A field mask decides what metagrab extracts and how much of the page it reads. On the 1.8 MB benchmark page, the head is about 17% of the HTML.

MetadataFields

Title, description, image, Open Graph, Twitter.

PreviewFields

Adds favicon and canonical URL.

RichFields

Adds JSON-LD, found anywhere in the page.

<head>, read<body>, readskipped

03How do I run it in production?

Eight practices for previews of URLs you don't control.

  • Block private networksIf users submit URLs, use WithDenyPrivateNetworks(). It checks every dial, redirects too, so a link can't reach 169.254.169.254 or your LAN.
  • Put a deadline on every callPass a context with a timeout and keep WithTimeout short. Slow sites should fail fast, not hold a request.
  • Reuse one clientCreate the Client once at startup and share it. Use WithRetries(2) for 429 and 5xx responses.
  • Use the smallest maskPreviewFields covers most previews and stops at </head>. Use RichFields only if you need JSON-LD.
  • Cache the resultsmetagrab does not cache. Store each Link by its canonical URL for hours or days. Pages rarely change their preview.
  • Branch on error codesEvery error is a *FetchError. Switch on Code, for example http_status_error or unsupported_content_type, not on the message.
  • Fetch lists in bulkFetchBulkResults runs in parallel (WithConcurrency) and gives one result per URL. One bad link does not fail the batch.
  • Say who you areSet WithUserAgent to your product name and a contact URL. Site owners can then reach you instead of blocking you.

A production client

Defaults without options: 10 s timeout, no retries, 5 redirects, 2 MB body limit, 10 parallel fetches. This client tightens them:

client := metagrab.NewClient(
    metagrab.WithDenyPrivateNetworks(),
    metagrab.WithTimeout(5 * time.Second),
    metagrab.WithRetries(2),
    metagrab.WithUserAgent("acme-previews/1 (+https://acme.dev/bot)"),
)

ctx, cancel := context.WithTimeout(ctx, 8*time.Second)
defer cancel()
link, err := client.Fetch(ctx, url, metagrab.PreviewFields)

04CLI and HTTP API

Same engine, no Go code needed. The server listens on port 8080 and takes one JSON body per request.

cli
brew install --cask josephgoksu/tap/metagrab
metagrab https://go.dev
http
docker run -p 8080:8080 ghcr.io/josephgoksu/metagrab
curl localhost:8080/fetch -d '{"url":"https://go.dev"}'
